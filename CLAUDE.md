# LightGame

Unity 6000.2.7f2, 2D URP platformer. Game code lives in `Assets/_Game`.

## Driving the editor

To play the game or change assets through Unity, use your own editor on a git worktree, never the
user's open one. Setup and the working loop are in `docs/agent-playtesting.md`; driver commands
are in the `playtest` skill.
